
# Demo2026
  
  
  
## Описание
**Решение Demo2026 по специальности 09.02.06 «Сетевое и системное администрирование»**
Данный репозиторий содержит скрипты по настройке сетевой инфраструктуры в соответствии с предложённой топологией. В документации описаны этапы базовой настройки, включая конфигурацию имён устройств, настройку IPv4, NAT, VLAN, туннелей GRE с динамической маршрутизацией (OSPF), настройку DNS, DHCP, ~~а также настройку контроллера домена Samba DC~~.
> **Важно:** 
> **В данный момент скрипты не доработаны, использовать на свой страх и риск!**
> Все примеры с указанием интерфейсов, IP-адресов, масок и шлюзов приведены сугубо в качестве примера. 
> В вашей сети данные параметры могут отличаться. Перед внесением изменений обязательно сверяйте настройки с актуальной топологией и требованиями вашей инфраструктуры.

## Как использовать
  
* Скачать git 
* Спулить с локального репо файлы
* Дать возможность выполнения
* Выполнить
```
apt-get install git  #Установка git
git clone https://lab.smolserver.ru/RxtPr/Demo2026 #Скачивание репо
cd Demo2026 #Открываем папку с репо
chmod +x ./название_скрипта.sh # Даем право выполнения скипа
./название скрипта.sh # Выполняем скрипт
```
